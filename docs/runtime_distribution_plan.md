# Notebook 模块：基于 10 次观测的 pipeline 耗时分布分析

## 目标与数据口径

新建 `descriptive_statistics.ipynb`，实现 **Module 1 — Pipeline Runtime Distribution**。所有说明、图表和结果解读使用英文；按分析单元组织小型 cells。

已确认原项目 profiles 包含 `run_01` 至 `run_10`，每轮 25 个候选，共 250 个有效耗时记录。用户确认各轮硬件、数据、代码、线程配置和 profiler 选项一致。

模块分别回答：

- **候选间差异：**哪些 pipeline 通常最耗时？
- **候选内波动：**同一个 pipeline 的 10 次耗时有多稳定？
- **成本集中度：**哪些候选和步骤持续贡献较多成本？
- **轮次效应：**是否存在整轮变慢或随轮次变化的现象？

仅使用 profile 的 `elapsed_time_sec`。重复观测仍属于 profiling 执行，不等同于无 profiler 的基线测量；各候选耗时之和不称为实测 trajectory 墙钟时间。

## 数据组织与统计方法

### 输入与验证

- 使用 manifest 定义候选和步骤，读取 `run_*/pipeline_*.json`，以 `(run_id, pipeline_id)` 作为唯一键。
- 当前工作区尚无 profiles，配置 cell 显式指向原项目的 profiles：`/Users/tue/Documents/10_Projects/deai-pro/profiles`；显示解析后的路径，允许手动修改，不静默切换数据源。
- 生成长表：`run_id`、`pipeline_id`、`step`、`step_name`、`elapsed_sec`、`start_time_absolute`、`source_path`。
- 校验 10×25 的覆盖矩阵；报告缺失、重复、损坏 JSON、无效耗时及额外候选。无效耗时不补零，不插补。
- 保留全部有效观测，包括箱线图中的离群点；不默认剔除第一轮或将其称为预热运行。

### 统计口径

- 每个 pipeline 报告有效次数、中位数、均值、样本标准差（`ddof=1`）、Q1、Q3、IQR、最小值、最大值和 CV（标准差/均值）。
- 使用中位数排序，IQR 描述主要波动范围；分位数使用线性插值。CV 作为辅助比较，不设置任意的“稳定/不稳定”阈值。
- 每轮先计算候选耗时占比、步骤耗时合计和步骤占比，再跨轮汇总。不得用“各候选中位数之和”替代“每轮总和的中位数”。
- 候选和步骤的平均轮内占比用于可加总的成本分解；完整轮次中的占比之和应为 100%。
- 固定 Top 5 为按跨轮中位数选出的五个候选，报告其各轮累计占比；另报告每个候选进入轮内 Top 5 的次数，并明确并列处理采用 manifest 顺序。
- 单候选统计使用其有效观测；跨候选占比、排名和步骤成本比较仅使用完整轮次，并显示纳入轮次数。
- 本模块采用描述统计，不加入显著性检验、置信区间或因果判断。10 次观测可描述波动，但不自动证明独立同分布。

## Cell 结构与图表

每个单元采用 **Markdown：问题与方法 → 小型 code cell → 输出 → Markdown：结果解释与局限**。计算和绘图分开，每个 code cell 通常为 10–30 行。

| 单元 | 说明重点 | 代码拆分与输出 |
| --- | --- | --- |
| 1. 目标与测量口径 | 区分候选间差异、重复运行波动和 profiling 开销 | 纯 Markdown |
| 2. 配置 | 依赖、输入路径、输出目录、预期轮次 | 两个 cells：导入与样式；路径配置与检查 |
| 3. 实验清单 | manifest 如何定义候选集合，目录如何定义 run | 两个 cells：候选清单；发现轮次与文件 |
| 4. 读取与质量检查 | 有效值规则与完整轮次定义 | 两个 cells：读取成长表；覆盖矩阵与问题表 |
| 5. 轮次概览 | 先检查是否存在整轮耗时差异 | 两个 cells：各轮耗时之和与采集时间表；按轮次排列的合计折线图 |
| 6. 单候选统计 | 每个候选以 10 次观测为一个统计组 | 一个 cell：生成并显示候选统计表 |
| 7. 候选耗时比较 | 用典型耗时排序，同时展示波动 | 一个 cell：按中位数降序的横向箱线图，叠加全部观测点 |
| 8. 波动与轮次效应 | 区分持续昂贵与偶发变慢 | 两个 cells：按 CV 排序的波动表；候选×轮次热力图，数值为耗时除以该候选中位数 |
| 9. 成本集中度 | 昂贵候选是否持续贡献大量成本 | 两个 cells：轮内占比、Top 5 频次和固定 Top 5 占比；平均占比排序及累计占比图 |
| 10. 步骤级成本 | 区分候选数量多与单候选耗时高 | 两个 cells：步骤×轮次合计及跨轮汇总；步骤耗时箱线图叠加轮次观测点，标注候选数量 |
| 11. 综合解读 | 观察 → 调查优先级 → 限制 | 纯 Markdown，结合实际结果撰写 |
| 12. 导出与复现 | 产物、数据来源和解读更新规则 | 一个 cell：导出表格、图像与输入指纹 |

共五张图。箱线图须解释中位数、箱体和 1.5×IQR 须线含义；叠加原始点时关闭重复的离群点符号。步骤颜色一致，时间轴注明秒；热力图明确为无单位比值。

不将全部 250 个值混成一个总体分布来解释“运行稳定性”，也不继续使用原单次观测计划中的直方图作为主要证据。

- 使用小型已知数据检查中位数、IQR、样本标准差，以及“先按轮求和、再跨轮汇总”的顺序。
- 验证缺失记录、损坏 JSON、无效耗时和无完整轮次时的行为；保留可用单候选分析，但停止不具备覆盖条件的整体比较。
- 检查图表可读性及全部英文解释与输出一致；不把高 CV、离群点或轮次趋势直接归因于某种系统机制。
